## Dependencies installation
```

apt update
apt install python3-pip -y
pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu128
pip install thop -i https://pypi.org/simple --no-deps
pip install einops -i https://pypi.org/simple --no-deps
pip3 install torch torchvision -i https://download.pytorch.org/whl/cu128
pip install lmdb -i https://pypi.org/simple --no-deps
pip install tensorboard -i https://pypi.org/simple --no-deps
pip install yacs -i https://pypi.org/simple --no-deps
```
